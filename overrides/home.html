;; clojure-lite-lsp

A Clojure LSP light enough to run in every worktree.

Working with coding agents means many codebases open at once: several projects, several worktrees of each, an agent or an editor in every one. clojure-lite-lsp uses about 20 MB per editor, and a new worktree indexes only the files that differ from ones already indexed. It stays that small by implementing only the parts of the language server protocol for reading and reviewing code--because who is writing code by hand anymore??
