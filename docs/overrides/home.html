// clojure-lite-lsp

Clojure navigation for every worktree, every editor, every agent.

A read-only Clojure language server built for many checkouts at once. Analysis from clj-kondo goes into one shared index: a library is analyzed once for the whole machine, a new worktree is ready in seconds, and each editor's server costs about 20 MB.

// what it gives you

Navigation

Go to definition, find references, implementations of protocols and multimethods, hover docs, file outlines, symbol search, call hierarchy, highlights and argument hints.

Built for worktrees

Analysis is keyed by content: a second worktree of a project indexes only the files that differ, in about 3 seconds for Metabase.

Low memory

Each editor's server is a small native process that reads the shared index. The indexer runs once for the machine and exits when idle.

For agents too

Claude Code uses it through its LSP tool, Codex through MCP, and any agent through clojure-lite-lsp query. One command sets a project up.

Branch-aware

Switching to a branch with a different clj-kondo config re-analyzes only the files that config change can affect.

Zed, VS Code and more

Extensions for Zed and VS Code; any editor with an LSP client can run clojure-lite-lsp lsp.
